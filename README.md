# Yaadi

Yaadi is a WhatsApp lead desk for businesses that sell on WhatsApp. It runs on the business's own computer, linked to its own WhatsApp number, and answers every new chat with a welcome in the customer's language, plans the follow-ups and keeps the sales pipeline.

This repository holds Yaadi's installers and updates, nothing else. The source code is private.

To install, open the [latest release](https://github.com/vinnaykulkarni/Yaadi-releases/releases/latest) and download `Yaadi-Setup.exe` for Windows, or `Yaadi-Mac-AppleSilicon.zip` or `Yaadi-Mac-Intel.zip` for a Mac. Yaadi starts with 7 free days, and an installed copy updates itself from here.
